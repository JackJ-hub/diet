# 饮食记录

一个纯前端的中文饮食记录 PWA:输入「米饭 1碗」这样的自然写法,自动估算热量、蛋白质、纤维,并统计每日与累计结余。无需服务器、无需账号。

## 安装到 iPhone 13 Pro

### A. 推荐:免费 GitHub Pages

1. 注册 GitHub 账号。
2. 新建一个 **public** 仓库,例如 `diet`。
3. 把本文件夹里的**所有文件**(含 `icons/` 文件夹)上传:网页端 "Add file → Upload files" 即可,不需要 git。
4. Settings → Pages → Deploy from branch,选择 `main` / `(root)`,保存。
5. 等约 1 分钟,在 iPhone 的 **Safari** 中打开 `https://<用户名>.github.io/diet/`。
6. 点底部「分享」按钮 → 「添加到主屏幕」。

### B. 同一 Wi-Fi 下本地快速测试

```
cd ~/Desktop/diet && python3 -m http.server 8000
```

Mac 上用 `ipconfig getifaddr en0` 查局域网 IP,然后在 iPhone Safari 访问 `http://<Mac局域网IP>:8000`。
注意:此模式下数据绑定在该地址,与正式地址的数据不互通,仅用于测试。

## 数据与备份

- 数据保存在手机本地(localStorage),首次加载后可离线使用。
- 建议定期:右上角 ⋯ → 「复制备份到剪贴板」,粘贴到「备忘录」保存。
- 恢复:⋯ → 「从备份恢复」,粘贴备份内容。

## 用法

输入写法示例:

- `米饭 1碗`
- `鸡胸肉 150g`
- `半碗粥`
- `两个鸡蛋`
- `拿铁 180卡`
- `蛋白棒 1根 200卡 20蛋白 5纤维`

不认识的食物会提供「Google 查询」,查到后手动填写数值,之后会被记住。

累计结余只统计今天**之前**的天数(不含今天)。

## 更新

修改文件后重新上传覆盖即可。如果手机仍显示旧版本,把 `sw.js` 里的缓存名(`diet-v1`)改成 `diet-v2` 等再上传,然后重新打开应用。
